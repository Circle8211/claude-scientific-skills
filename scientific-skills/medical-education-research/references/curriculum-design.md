# Curriculum Design in Medical Education

## Kern's Six-Step Approach

The most widely used framework for curriculum development in medical education.

### Step 1: Problem Identification and General Needs Assessment

**Purpose**: Identify the health care problem that the curriculum will address.

**Activities**:
- Review epidemiological data
- Analyze health care delivery patterns
- Examine current approaches and their limitations
- Consider societal needs and expectations

**Key Questions**:
- What is the problem?
- Whom does it affect?
- What are the current approaches?
- What is ideal vs. actual practice?

### Step 2: Targeted Needs Assessment

**Purpose**: Determine the specific needs of your target learners.

**Methods**:
| Method | Description | Advantages | Limitations |
|--------|-------------|------------|-------------|
| Surveys | Written questionnaires | Large sample, anonymous | Low response, superficial |
| Interviews | One-on-one discussions | In-depth, flexible | Time-intensive, bias |
| Focus groups | Group discussions | Interactive, rich data | Dominant voices, logistics |
| Direct observation | Watch learners perform | Objective, actual behavior | Observer effect, sampling |
| Chart review | Analyze documentation | Objective data | Retrospective, completeness |
| Testing | Assess knowledge/skills | Objective measures | Test anxiety, validity |

**Stakeholder Analysis**:
- Learners (current knowledge, skills, attitudes)
- Faculty (teaching capabilities, resources)
- Patients (needs, expectations)
- Health system (requirements, constraints)

### Step 3: Goals and Objectives

**Goals**: Broad, general statements of intent
**Objectives**: Specific, measurable outcomes

**Hierarchy**:
```
Program Goals
    ↓
Course/Rotation Goals
    ↓
Session/Unit Objectives
    ↓
Specific Learning Objectives
```

**Writing Objectives**:
1. Use observable action verbs
2. Specify conditions
3. Define criteria for success
4. Align with appropriate cognitive level

**Bloom's Taxonomy Application**:
```
Level 1 (Remember): Define, list, recall, identify
Level 2 (Understand): Explain, describe, summarize, classify
Level 3 (Apply): Demonstrate, solve, use, implement
Level 4 (Analyze): Compare, contrast, differentiate, examine
Level 5 (Evaluate): Assess, critique, judge, justify
Level 6 (Create): Design, develop, formulate, construct
```

### Step 4: Educational Strategies

**Selecting Methods**:

| Domain | Effective Strategies |
|--------|---------------------|
| Knowledge | Lectures, readings, online modules, case discussions |
| Skills | Simulation, supervised practice, deliberate practice |
| Attitudes | Role modeling, reflection, patient interactions |
| Behaviors | Feedback, coaching, progressive independence |

**Active Learning Strategies**:
- Problem-based learning (PBL)
- Team-based learning (TBL)
- Case-based learning (CBL)
- Flipped classroom
- Simulation-based education
- Peer teaching

**Experiential Learning (Kolb's Cycle)**:
```
Concrete Experience
       ↓
Reflective Observation
       ↓
Abstract Conceptualization
       ↓
Active Experimentation
       ↓
(returns to Concrete Experience)
```

### Step 5: Implementation

**Key Considerations**:
- Resources (faculty, space, equipment, funding)
- Support (administrative, technical, political)
- Barriers (resistance, competing priorities, logistics)
- Pilot testing before full rollout

**Faculty Development**:
- Teaching skills workshops
- Assessment calibration
- Curriculum orientation
- Ongoing support and feedback

**Implementation Phases**:
1. Pilot with small group
2. Gather feedback and revise
3. Expand gradually
4. Full implementation
5. Continuous monitoring

### Step 6: Evaluation and Feedback

**Formative Evaluation**: Ongoing monitoring to improve curriculum

**Summative Evaluation**: End assessment of curriculum effectiveness

**Kirkpatrick's Levels**:
| Level | Focus | Examples |
|-------|-------|----------|
| 1 - Reaction | Satisfaction | Course evaluations |
| 2 - Learning | Knowledge/skills gained | Tests, OSCEs |
| 3 - Behavior | Application to practice | Workplace observation |
| 4 - Results | Patient/system outcomes | Quality metrics |

## ADDIE Framework

### Analysis
- Identify learning needs
- Define target audience
- Determine constraints
- Establish timeline

### Design
- Define learning objectives
- Structure content sequence
- Select delivery methods
- Plan assessments

### Development
- Create instructional materials
- Develop assessments
- Build technology components
- Pilot test materials

### Implementation
- Deliver instruction
- Facilitate learning
- Provide support
- Manage logistics

### Evaluation
- Collect feedback
- Measure outcomes
- Identify improvements
- Revise and iterate

## Backward Design (Understanding by Design)

### Stage 1: Identify Desired Results
- What should students know and be able to do?
- What understandings are desired?
- What essential questions will guide learning?

### Stage 2: Determine Acceptable Evidence
- How will we know if students achieved the desired results?
- What evidence will demonstrate understanding?
- What assessment tasks are needed?

### Stage 3: Plan Learning Experiences
- What activities will help students learn?
- How do we sequence instruction?
- What resources are needed?

## Competency-Based Medical Education (CBME)

### Core Principles
1. Focus on outcomes/competencies
2. Emphasis on abilities, not time
3. Learner-centered approach
4. Assessment for learning
5. Flexible time progression

### Implementation Framework

**Competency Definition**:
```
Competency = Knowledge + Skills + Attitudes
             applied in specific contexts
             to achieve defined outcomes
```

**Milestones**: Developmental markers along the continuum from novice to expert

**Entrustable Professional Activities (EPAs)**: Tasks that can be entrusted to a learner once competence is demonstrated

**Example EPA Structure**:
```
EPA Title: [Clinical activity]
Description: [What the activity involves]
Required Competencies: [Which competencies map to this EPA]
Supervision Scale:
  1 - Not allowed to perform
  2 - Allowed to perform with direct supervision
  3 - Allowed to perform with indirect supervision
  4 - Allowed to perform independently
  5 - Allowed to supervise others
```

## Integrated Curriculum Design

### Horizontal Integration
Connecting disciplines at the same level (e.g., combining anatomy with physiology)

### Vertical Integration
Connecting basic and clinical sciences across years

### Spiral Curriculum
Revisiting topics at increasing complexity

**Benefits**:
- Reduces redundancy
- Promotes connections
- Enhances retention
- Supports application

### Integration Strategies
- Organ system-based modules
- Clinical presentations as organizing framework
- Problem-based integration
- Case-based threads
